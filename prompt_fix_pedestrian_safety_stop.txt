Eres el agente de automatización e ingeniería para el proyecto Unity "Primer Volante" (Unity 6 LTS, C#, PhysX).

### PROBLEMA REPORTADO (Efecto Acordeón / Aproximación a tirones):
Tanto en vehículos NPC como en peatones, ocurre un comportamiento oscilatorio indeseado cuando el jugador se detiene frente a ellos:
1. El NPC avanza hacia el jugador a velocidad normal. Su caja/área de detección frontal se extiende proporcionalmente por la velocidad (`m_DynamicDistanceWithSpeed` = true, lookahead).
2. En cierto momento, el borde delantero de la caja de detección alcanza al vehículo del jugador y activa el frenado de emergencia (`EmergencyStop()`).
3. Al detenerse el NPC (velocidad = 0 m/s), la distancia efectiva calculada por `GetEffectiveDetectionDistance()` se contrae súbitamente a solo `m_DetectionDistance` (la velocidad cayó a 0).
4. Como la caja se achicó, el jugador (que estaba a mayor distancia) queda fuera del área contraída.
5. El NPC cree erróneamente que la vía quedó despejada (`obstacleDetected = false`), espera el `m_ResumeDelay` (0.5s - 0.6s) y vuelve a arrancar (`Play()`).
6. Al acelerar, la velocidad aumenta y la caja se estira de nuevo hacia adelante, redetectando al jugador unos milímetros o centímetros más cerca.
7. Se vuelve a frenar a 0, la caja se vuelve a achicar, deja de detectarlo, espera y vuelve a avanzar...
8. Resultado: El NPC avanza a pequeños tirones aproximándose progresivamente hasta colisionar físicamente con el jugador.

---

### CAUSA RAÍZ Y SOLUCIÓN DE INGENIERÍA:
Falta de **Histéresis de Detección** (Detection Hysteresis) y persistencia del rango de frenado en `NPCSafetyStop.cs`:
- Cuando el NPC entra en frenado de emergencia (`m_IsEmergencyBraking = true`), la distancia de detección frontal **NUNCA debe contraerse al caer la velocidad a cero**.
- Debe retener la distancia efectiva que tenía al momento del frenado (`m_BrakingDetectionDistance`), más un margen de histéresis de seguridad (`m_ResumeHysteresisDistance`), asegurando que el obstáculo detectado permanezca dentro del sensor mientras siga en la misma posición.

### INSTRUCCIONES DE IMPLEMENTACIÓN:

#### 1. En `Assets/Scripts/Environment/NPCSafetyStop.cs`:
- **Campos y propiedades de histéresis**:
  - Agregar campo serializado:
    ```csharp
    [Tooltip("Margen de histéresis en metros sumado a la distancia de frenado mientras el NPC permanece detenido. Evita oscilaciones por contracción del sensor a velocidad cero.")]
    [SerializeField] private float m_ResumeHysteresisDistance = 0.5f;
    ```
  - Exponer propiedad pública `public float ResumeHysteresisDistance { get => m_ResumeHysteresisDistance; set => m_ResumeHysteresisDistance = Mathf.Max(0f, value); }`.
  - Campo privado: `private float m_BrakingDetectionDistance = 0f;`.
- **Actualizar `GetEffectiveDetectionDistance()`**:
  ```csharp
  public float GetEffectiveDetectionDistance()
  {
      float distance = m_DetectionDistance;

      // Si el NPC está en frenado de emergencia, nunca reducir la distancia del sensor al caer a velocidad cero:
      // Mantener la distancia registrada al momento del frenado más el margen de histéresis.
      if (m_IsEmergencyBraking && m_BrakingDetectionDistance > 0f)
      {
          return Mathf.Max(distance, m_BrakingDetectionDistance + m_ResumeHysteresisDistance);
      }

      if (m_DynamicDistanceWithSpeed && m_PathFollower != null)
      {
          distance += m_PathFollower.CurrentSpeed * m_SpeedLookaheadFactor;
      }

      return Mathf.Max(0.2f, distance);
  }
  ```
- **En `Tick(float deltaTime)`**:
  - Cuando `obstacleDetected == true`:
    - Si `!m_IsEmergencyBraking`:
      - Registrar `m_BrakingDetectionDistance = GetEffectiveDetectionDistance();` ANTES de frenar el seguidor.
      - Activar `m_IsEmergencyBraking = true;` y llamar a `m_PathFollower.EmergencyStop();`.
    - Si `m_IsEmergencyBraking` ya era true:
      - Mantener la parada de emergencia y no dejar que avance.
  - Cuando `!obstacleDetected`:
    - Al cumplirse `m_ClearTimer >= m_ResumeDelay`:
      - Al reanudar la marcha y desactivar la emergencia (`m_IsEmergencyBraking = false`), restablecer `m_BrakingDetectionDistance = 0f;`.
- **En `ForceEmergencyBrake(Collider col)`**:
  - Si `!m_IsEmergencyBraking`:
    - Registrar `m_BrakingDetectionDistance = GetEffectiveDetectionDistance();`.
- **En `ResetSafetyState()`**:
  - Restablecer `m_BrakingDetectionDistance = 0f;`.
